# FAQ: learning

> Обезличенные демонстрационные данные для acceptance-тестов. Это не реальные политики компании. Контакты, ссылки и числовые правила — тестовые примеры.

<a id="course-catalog"></a>
## Какие курсы доступны?
Демо-каталог курсов: https://learning.example.invalid/catalog. Выберите курс из каталога.

<a id="training-approval"></a>
## Как согласовать обучение?
Демо-шаги согласования: выберите курс, отправьте руководителю цель и стоимость, дождитесь согласования, затем передайте заявку HR: hr@example.invalid.

<a id="training-budget"></a>
## Есть ли бюджет на обучение?
Демо-правило: лимит обучения — 10000 условных единиц на сотрудника за календарный год после согласования руководителя. Это вымышленный тестовый лимит, не обещание выплаты.
