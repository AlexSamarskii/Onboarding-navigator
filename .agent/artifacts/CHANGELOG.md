# Журнал изменений

Значимые изменения HR-расширения описаны в формате Keep a Changelog. Версия 0.1.0 обозначает этот этап документации; версия исходного пакета и метаданные сборки не менялись.

## [0.1.0] - 2026-10-23

### Добавлено

- HR-адаптеры: цитирование, детерминированная диагностика, тикетинг, аналитика неотвеченных запросов.
- Механизм i18n и русская локаль из 124 конечных ключей.
- Пять YAML-режимов, варианты плана онбординга и план по умолчанию.
- `HRFAISSProvider(LocalFAISSProvider)` с порогом сходства 0.65 и координацией индексов.
- Dockerfile, .dockerignore, корневой .gitignore, манифест Kubernetes и наложение конфигурации образа.
- Воспроизводимый автономный нагрузочный инструмент `tests/load/run_baseline.py`.
- Покрытие офлайн-тестами 78.006% (AC-N10 ≥ 78%).
- Документация выпуска и сохранённое уведомление MIT исходного проекта.

### Изменено

- Обработчики: 47 устаревших литералов заменены переводами, подключены HR-адаптеры.
- Main: bootstrap_components, ProviderObserver, RequestScopedRouter, узкое разрешённое исправление legacy reload.
- Загрузчик режимов: валидация необязательных полей и три помеченных резервных legacy-литерала.
- Загрузчик конфигурации: валидация продуктового конфига с сохранением прежнего контракта.
- Менеджер сессий: TTL профиля, diagnostics_state, rag_fallback_streak, active_ticket_uuid.
- Метрики: пять дополнительных серий в существующем registry.
- Совместимый legacy-обработчик извлечён и исключён из покрытия; реальные пути rag_chains проверяются через LCEL с тестовыми заменами.

### Исправлено

- Найденная при ревью гонка в `HRFAISSProvider.load_index`.
- Найденное при ревью использование datetime без часового пояса в `session_manager.set_session`.
- Перезагрузка legacy Router больше не добавляет HR-observers безусловно.
- Предложения при fallback: устранение дублей и стабильный порядок по оценке/тексту.
- Найденные при ревью дубли устаревших UI-ключей в ходе утверждённой миграции.
- Цель RAG в инфраструктурном dry-run исправлена на 200 мс; реальный замер поиска остаётся недоступен.

### Заменено

- Wiring-тест `test_i18n_keys_used.py` архивирован как `.py.superseded`; исходный SHA256 `81b87f6526a3c86d3dd0fa4946b454c835fc11949165c90730586cbcf6f68e63`; замена `backend_rest_i18n_checks/test_legacy_and_ui_cyrillic.py` сохраняет legacy-логику и проверяет активные инварианты i18n.
